# 教学实验工作台视觉规范

保留 YunLevel 深色教学界面，用清晰读数和稳定的操作层级帮助搭建回路与整定 PID。原生 HTML/CSS/JS，无新增字体、图标或运行依赖。

| 项目 | 约定 |
| --- | --- |
| 背景 / 面板 | `#0E151D` / `#16222E` |
| 主文字 / 次文字 | `#EDF3F8` / `#A9BBCB` |
| 主操作 | `#33CDA6`，用于启动、应用及选中状态 |
| 字号 | 正文 14px，标签至少 12px，常驻读数 22px |
| 数字 | 等宽数字对齐，单位随测量值显示 |
| 圆角 | 面板 12px，控件 8px |
| 间距 | 4 / 8 / 12 / 16 / 24px，组内紧凑、组间留白 |

控制操作集中在顶部；回路选择与手操位于左栏，仿真图居中，选中回路参数位于右栏。1440px 起使用三栏，900–1439px 将参数栏移至图下，900px 以下按照 DOM 顺序纵向排列。折叠工程方案、搭建工具、全部检测值及 PID 计算，保留常用动作和关键读数。

颜色之外同时提供文字状态：未应用、应用中、已应用、失败、只读、禁用。侧栏直接填写数字，不再弹出滑块；设备操作卡保留内嵌滑块，应用按钮明确下发。请求失败或回复较晚时保留未提交草稿。可编辑字段具有可见键盘焦点；原生下拉框沿用深色模式，响应减少动画偏好。

关键测量值和回路 PV 从当前模型的 SSE 状态读取，缺值显示“—”。绘图缩放后设备标注可能变小，图下常驻读数始终保持固定字号，可通过放大、适配和全屏查看工艺结构。

曲线、评分及教师管理页继承通用控件、色彩和焦点样式，结构保持现有版本。权限和评分规则由服务器决定，本规范不增加命令或修改规则。

## 质感与操作动效

串级参数以语义化 fieldset 分成主环、副环，各自展示实时 PV 和 PID 字段；统一标题到 PV 的 8px 间距。应用参数为主操作，模式/作用切换为次操作，删除保持独立危险样式。回路列表使用边框、底色和文字共同表达当前选择；工艺图只调整标签、线条端点和圆角，设备位置、世界尺寸和相机不变。

| 操作 | 反馈 |
| --- | --- |
| 选择不同回路 | 原表单立即切换；160ms 水平 6px 与透明度过渡 |
| 同一回路重复选择 / SSE | 不播放切换动画；读数直接更新 |
| 应用中 | 小型加载指示与“应用中…”文字，阻止重复提交 |
| 应用成功 | “参数已应用”及静态确认图形，180ms 局部颜色反馈一次 |
| 失败 / 请求期间又编辑 | 稳定错误或未应用提示，保留草稿，不播放成功确认 |

短动效统一使用 `cubic-bezier(0.16,1,0.3,1)`，不等待动画完成再响应输入。旋转加载指示使用匀速循环。快速切换取消上一条动画，迟到的动画完成通知不能清理新动画；最终样式由 CSS 决定，不遗留透明度或 transform。页面隐藏时取消动效、停止加载与工艺效果；重新可见不重播。系统减少动画偏好保留文字、静态确认和只读状态，取消位移、缩放及加载旋转。无 WAAPI 时内容直接可用，不添加运行依赖。

## 工艺图设备操作卡

设备入口保留既有图形，以屏幕至少 44px 的透明命中区域补充鼠标、触屏和键盘操作。桌面操作卡贴近设备并限制在视口内，900px 以下改为底部面板，内部可滚动且考虑安全区。一次只显示一个卡片，选中设备使用轮廓与按压状态共同表达。

沿用面板色、12px 圆角、12px 标签和 22px 等宽读数；显示单位，缺值使用“—”。优先显示 SP、输出及明确的应用动作，PID 默认折叠，串级按主副环分组。写入限制、草稿、失败与等待均提供文字，不单独依赖颜色。卡片与侧栏共用表单，详见《工艺图设备操作与验证.md》。
