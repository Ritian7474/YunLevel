## 一、项目定位

本项目把原桌面版三级液位 PID 仿真改造成服务器多用户版本，面向大学课堂使用：

- 学生通过“班级码 + 学号 + 姓名”登录，每人使用独立仿真会话；
- 教师使用一个总教师账号管理所有班级、查看学生状态和评分；
- 仿真内核使用 C++17，浏览器前端通过 Node.js 网关与内核通信；
- 当前测试版使用 `http://服务器公网IP:8080`，暂不依赖域名、HTTPS 和备案；
- 数据保存在服务器 `data/` 目录，容器重建不会主动删除数据。

## 二、当前架构

| 层级 | 技术 | 作用 |
| --- | --- | --- |
| 仿真内核 | C++17 | `YunEngine` 液位内核 + `HxEngine` 换热器内核；共用 DCS 口径 PID |
| 服务网关 | Node.js 18+ | 登录、会话隔离、状态保存、SSE 推送、教师接口 |
| 前端 | 原生 HTML/CSS/JavaScript | 控制、仿真图、曲线、评分、教师看板和班级管理 |
| 部署 | Docker Compose | 单机部署、数据卷挂载、容器重建 |

主要目录：

- `native/`：C++ 仿真内核；
- `native-hx/`：换热器无界面内核，目录与液位隔离；
- `server/`：Node 网关、班级名单、快照和评分记录；
- `public/`：浏览器页面；
- `docs/`：部署、使用、评分、班级管理和本进度文档；
- `data/`：运行期数据，不放入源码部署包。

## 三、已完成功能

### 1. 登录、班级和会话

- 学生登录校验班级码、学号、姓名和启用状态；
- 一个总教师账号管理全部班级；
- 每名学生的仿真进程按“班级 + 学号”隔离；
- 同一班级重复登录同一学号时，旧会话退出并自动保存一份恢复快照；
- 同一学号重新登录时，旧登录令牌立即失效，旧浏览器不能继续读取状态或发送控制；
- 教师演示使用独立会话，不进入学生在线列表和评分记录；
- 单台服务器默认最多 120 个学生会话，可通过环境变量调整。

### 2. 班级管理

- 新建、修改、启用、停用和删除班级；
- 添加、修改、停用和删除学生；
- 支持 Excel、CSV 和手动文本名单导入；
- 支持“合并导入”和“覆盖导入”；
- 支持导出当前班级名单 CSV；
- Excel/CSV 读取第一张工作表并自动识别学号、姓名列。

### 3. 控制 / 仿真

- 启动、暂停/继续、回到冷态；
- 单回路和串级方案只能在不运行时切换；
- 单回路自由选择被控量和阀门；
- 串级自由选择阀门、主环和副环，也可在同一方案中搭单回路；
- 同一阀门禁止被重复回路或不同控制器占用；
- 阀门冲突、重复回路、回路数量超限和非法编号都返回结构化错误码，前端显示中文原因；
- 泵 P101 和 FV101～FV104 手操；
- 已被回路占用的阀门禁止使用阀门外手操，需在回路卡片中处理；
- 前馈偏置开关，默认关闭；
- 回路卡显示只读 PV、SP、Kp、Ti、Td、手动输出和当前控制状态；
- 回路卡支持应用参数、投手动/自动、改正作用/反作用、删除；
- Ti 输入 `inf` 表示不投入积分，内部遵循 `Ki = 1 / Ti`；
- `Ti=0`、NaN 等非法值会被拒绝，不会退化为超强积分；
- 回路卡标题按“测量到控制”显示，单回路为“PV → MV”，串级为“主环 PV → 副环 PV → MV”；
- PID 空状态不显示计算过程，添加回路后才显示；
- PID 过程显示 `e = SP - PV`、P/I/D、偏置和实际输出 `u(t)`；
- 仿真画面包含泵、真实阀门、储罐和连接管道，支持缩小、放大和全屏；
- 仿真画面显示三罐 SP 游标、液位 `% + mm`、管段流量标签、流动效果和阀门控制方式；
- 仿真图可叠加单回路、串级主环和副环控制线，并可一键隐藏；
- 暂停后任何 `TICK 1` 都不会推进仿真或解除暂停；
- 无回路、泵阀均为 0 等空跑场景会先给出提示；
- PID 计算过程可显示或收起。

### 4. 曲线

- 液位、流量、开度分为三个独立页面；
- 液位曲线使用 `%`，不使用 mm；
- 流量曲线单位 `L/min`，Y 上限可在 `1～20 L/min` 之间填写，留空为自动缩放；
- 位号图例可点击隐藏或显示对应曲线；
- 标注线可隐藏或显示，显示时可拖动；
- 当前时间标可拖动，避免遮挡曲线；
- X 轴、Y 轴可拖动缩放；
- 绘图区可拖动平移；
- 支持“最新视图”和“清空曲线”；
- 曲线历史按后台已有规则继续追加，回到冷态不清空曲线，只有“清空曲线”会清空；
- 教师查看学生实时曲线时也具备图例显隐、坐标拖动和标注线交互。
- 学生当前不导出曲线图片；学生点击“上传云端”时，由前端离屏重绘并上传液位、流量、开度三张 PNG。
- 旧的实时曲线图片导出入口当前隐藏，相关实现保留备用。

### 5. 评分

- 单罐评分和系统评分，两者满分都是 100；
- 单罐评分可选择 LI101、LI102 或 LI103；
- 评分方案和评分对象只能在不运行时切换；
- 开始评分时清空当前回路配置、回到冷态并启动评分计时；
- 评分计时默认限时 1800 秒（30 分钟）；
- 评分结束后成绩封存，可继续运行仿真但不再累计本轮评分；
- 评分项包括操作、控制、安全、收益；
- 低限扣分从储罐投运并达到低限条件后开始；
- 评分记录包含学生、班级、仿真时间、分项得分和回路/PID 快照；
- 教师端可查看、按班级筛选、导出 CSV 和按筛选范围清空记录；
- 评分未开始或未结束时不能进入结果页；点击评分标签会提示当前状态，评分结束后才解锁。
- 开始评分前有确认提示，并明确会清空回路与泵阀配置。

### 6. 状态保存、方案和工程文件

- “保存当前状态”允许冷态保存，也允许暂停后保存；仅“运行中且未暂停”拒绝保存；
- “恢复上传保存状态”恢复后统一为未启动状态；
- 每名学生有云端方案 1、2、3 三个保存位；
- “上传云端”要求仿真暂停，并且教师开放学生上传；
- “上传云端”会同时保存仿真状态、参数快照、曲线视图和三张曲线 PNG；
- “从云端下载”会替换当前仿真状态，恢复后为未启动；
- 教师端导出自己的工程时生成 `.ylproj` 文件；暂停状态可先自动保存再导出，未运行但已有保存状态时可直接导出；
- 学生端不提供参数、曲线和工程导出；教师端保留自己的工程导入导出能力；
- 导入工程文件上限 8 MB，导入后覆盖当前状态并恢复为未启动；
- 学生正常退出、重新登录或强制离开页面时，服务器会尽量保存一份自动恢复快照；
- 学生每次重新登录先进入全新的冷态界面，不会自动铺回上一次界面；需要手动点击“恢复上传保存状态”或从云端方案下载。

### 7. 教师看板

- 在线学生列表，可按班级和模型筛选，支持“全部模型 / 三级液位 / 换热器”；
- 在线学生、云端方案和评分记录均显示“模型”列；
- 显示学生运行状态、三罐液位、回路数量、评分状态；
- 查看指定学生实时液位、流量和开度曲线；
- 多台教师 PC 可打开看板，但教师仿真本身共用一个教师会话；
- 读取学生云端方案到教师仿真，读取前自动备份教师状态；
- 可恢复读取学生方案前的教师状态；
- 可导出学生云端方案；
- 查看评分记录并导出 CSV；
- 教师可开放或关闭学生“上传云端”权限；
- 教师独有推荐工况和高分模板，学生端隐藏这些入口。
- 教师可按班级选择学生或全选本班，只导出学生已上传的云端方案 1；
- 云端导出 ZIP 包含班级参数汇总、导出清单、每名学生参数 CSV、液位/流量/开度 PNG 和导出状态；
- 导出文件名、CSV 表头和 ZIP 子目录均带模型名；全部模型导出使用“全部模型”并按模型分目录；
- 教师导出不读取学生在线状态，不从实时曲线临时生成图片；
- 旧的在线参数导出和实时曲线图片导出实现保留，但前端入口当前隐藏。

## 五、数据持久化与部署

服务器数据卷为 `/opt/YunLevel/data`，主要文件：

- `classes.json`：班级、班级码和学生名单；
- `state/`：学生当前运行状态；
- `history/`：学生曲线历史；
- `score_records.jsonl`：评分记录；
- `settings.json`：教师开放学生上传等全局设置；
- `submissions/`：学生云端方案；
- `teacher_backups/`：教师读取学生方案前的自动备份；
- `runtime/`：活动会话运行文件。

部署脚本会先备份服务器 `data/`，再替换程序文件并重建 Docker 容器。不要手工删除服务器 `data/`，除非已明确备份并确认要清空学生数据和评分记录。

## 六、已知限制和后续事项
