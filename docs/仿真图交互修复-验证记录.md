# 仿真图交互修复与验证

日期：2026-10-04。分支 `fix/simulation-pan-zoom`，基线 `main` 的 `ffb2720`。
本 PR 独立修复前端交互，不包含核心可靠性 PR 的网关、内核、评分或权限修改。

## 行为变化

- 初次打开按显示区域适配完整图形，不再从固定宽度画布的一部分开始查看。
- 普通视图和全屏视图都支持主指针拖动，拖动没有过渡动画。
- `+ / −` 以视图中心缩放，范围从当前适配比例到 180%；边界处禁用对应按钮。
- 放大后的图形限制在可查看边界内，小于区域的轴居中；“适配”恢复全图。
- 每个模型分别保留普通、全屏两种视图的缩放和关注位置。切换全屏、控制／曲线等页面不会清空。
- 适配模式随区域尺寸变化重新适配；手动视图保持缩放和关注位置，并在必要时约束到新边界。
- 视图保存在当前页面内存，刷新后重新适配，不改变实验配置、快照或评分运行态。
- 指针取消、捕获丢失、鼠标松开、窗口失焦和切换图形均终止拖动；右键和第二个触点不会抢走正在进行的拖动。

## 浏览器验收清单

本机内置浏览器已验证 1536×724 和 800×724 的布局与适配；两模型普通视图拖动均可用，
拖动期间计算样式为 `transition-duration: 0s`。换热器普通视图在全屏与曲线页往返后
保持同一 transform；液位普通和全屏视图各自在往返后保持同一 transform。
隐藏／显示 PID 面板能重新适配，新建回路后 PID 卡片、控制接线正常显示；控制台未出现错误。

在独立本机预览中逐项检查，两模型均适用：

1. 首次登录后图形完整位于视口内，指标区不被画布遮挡。
2. 点击放大后水平、垂直拖动，图形立即跟随；松开后移动不再改变图形。
3. 向两端拖动不会丢失整幅图，点击“适配”能恢复。
4. 改变窗口宽度或显示／隐藏 PID 面板，适配视图随区域变化重新适配。
5. 普通视图放大和拖动后进入全屏，在全屏改变缩放，再退出，普通视图恢复原位置。
6. 全屏视图再次进入时恢复自身位置；Esc、按钮退出均可用。
7. 切到曲线再返回控制页，原视图保留；切换模型不互相覆盖。
8. 页面控制、搭建回路与 PID 操作继续可用，浏览器无新增控制台错误。

不连接现有测试或生产服务器，不合并或部署。
