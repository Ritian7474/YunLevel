三级液位 PID 云仿真  学生端功能手册
========================================

版本：当前 YunLevel 云版
更新日期：2026-09-24

一、登录
--------------------------------
1. 在浏览器打开老师提供的网址，例如：

   http://服务器公网IP:8080

2. 选择“学生登录”。
3. 在“实验模型”中选择老师当前开放的模型：
   - 三级液位；
   - 换热器（只有教师在教师端开放后才显示）。
4. 输入老师发给本班的：
   - 班级码；
   - 学号；
   - 姓名。
5. 姓名必须和班级名单完全一致，完成后点“进入仿真”。

说明：
- 每名学生的回路、参数、曲线、评分和云端方案互不影响；
- 同一班级重复登录同一学号时，后登录的会话会接替前一个；
- 每次重新登录先显示全新的冷态界面，不会自动把上一次界面铺回来；
- 需要继续以前的工作时，使用“恢复上传保存状态”或“从云端下载”。

二、页面结构
--------------------------------
学生端有四个主要操作区：

1. 控制 / 仿真
   控制区、仿真状态图、实时检测值、回路卡和 PID 计算过程。

2. 曲线
   液位曲线、流量曲线、开度曲线三个独立页面。

3. 评分
   选择评分方案、查看评分时间、分项得分和评分结果。

4. 退出
   右上角“退出”会结束当前会话，并尽量自动保存一份恢复快照。

三、控制区基本操作
--------------------------------
启动
  开始推进仿真。启动后“未启动”变成“运行中”。
  未搭建回路且泵阀手操都为 0 时，系统会先提示，不直接进入空跑。

暂停
  第一次点“暂停”进入暂停状态，再点一次继续运行。

回到冷态
  只有暂停状态才能点击。
  该操作会把液位、阀门、回路和评分状态复位为冷态。
  评分过程中回到冷态会结束本轮评分。

单回路 / 串级
  只能在未启动时切换。
  运行中按钮不可用，以免两套回路配置混在一起。
  单回路页和串级页各自保留一套单回路配置。

四、手操
--------------------------------
泵 P101
  可直接填写 0～100 的开度，点“应用手操”生效。

FV101～FV104
  未被回路占用的阀门可以直接填写手操值。
  已被回路占用的阀门输入框会禁用，必须进入对应回路卡调整参数或手动输出。

应用手操
  会应用泵和所有未被回路占用的阀门手操值。

前馈偏置
  “前馈偏置：关 / 开”，默认关闭。
  打开后 PID 输出会叠加给水前馈偏置，用于抵消静态偏差。
  当前状态会显示“开”或“关”。

清空回路
  清空当前方案下的回路卡。运行中操作前请先暂停。

五、搭建回路
--------------------------------
1. 单回路

   回路类型选择“单回路”。
   “被控量”可以选：

   - LI101 1#罐液位；
   - LI102 2#罐液位；
   - LI103 3#罐液位；

   FI101～FI103 只在串级方案中作为主环或副环使用。

   再选择阀门 FV101～FV104，点“添加”。

2. 串级

   先切换到“串级”方案。
   回路类型选择“串级”。
   依次选择：
   - 阀门；
   - 主环；
   - 副环。
   点“添加”，生成主环 + 副环的串级回路。

3. 搭建限制

   - 同一个阀门不能被两个回路同时控制；
   - 完全相同的回路组合不能重复添加；
   - 串级方案中仍可搭建单回路；
   - 串级和单回路共同遵守阀门占用限制；
   - 阀门冲突、重复回路、回路数量超限都会返回明确提示；
   - 运行中不要切换单回路和串级方案。

六、回路卡
--------------------------------
每张回路卡显示当前控制路径和实时数据。

单回路卡
  标题格式为：被控位号 → 阀门。
  例如：LI103 → FV102。

  卡片内容：
  - PV：实时被控量，只读；
  - SP：设定值；
  - Kp：比例增益；
  - Ti：积分时间；
  - Td：微分时间；
  - 手动输出；
  - 当前是手动还是自动；
  - 当前是正作用还是反作用。

串级卡
  标题格式为：主环 PV → 副环 PV → 阀门。
  卡片显示：
  - 主环 PV；
  - 副环 PV；
  - 主环 SP、Kp、Ti、Td；
  - 副环 Kp、Ti、Td；
  - 主副环手动/自动状态；
  - 主副环正反作用。

应用参数
  修改 SP、Kp、Ti、Td 或手动输出后，点“应用参数”写入内核。
  应用成功会在页面显示提示。

Ti 规则
  Ti 可以填写数字，也可以填写 inf。
  Ti 必须是有限正数或 inf；填写 0 会被拒绝并给出提示。
  inf 表示积分时间趋于无穷大，因此：
      Ki = 1 / Ti，Ki 趋于 0。
  inf 不是把 Ti 直接设为 0。

投手动 / 投自动
  手动状态使用回路卡中的“手动输出”。
  自动状态由 PID 计算输出。

改正作用 / 改反作用
  正作用：PV 高于 SP 时，PID 输出向增大方向变化。
  反作用：PV 高于 SP 时，PID 输出向减小方向变化。
  三级液位中的液位回路通常使用反作用；如果方向相反，阀门可能不动或越调越偏。

删除
  删除当前回路卡并释放该阀门。

七、PID 计算过程
--------------------------------
- 没有添加回路时显示“暂未添加回路”；
- 添加回路后自动显示计算过程；
- 单回路显示：
      偏差 e = SP - PV；
      P / I / D；
      偏置；
      输出 u(t)。
- 串级显示主环和副环各自的偏差、P、I、D 和输出；
- 控制区标题栏可“显示 PID”或“隐藏 PID”；
- u(t) 不使用“只把 P+I+D 当成最终输出”的错误近似，界面同时显示偏置项。

八、仿真画面
--------------------------------
仿真图按工艺流程排列：

   P101 泵 → FV101 → 1#罐 → FV102 → 2#罐 → FV103 → 3#罐 → FV104

仿真图显示：
- 泵和阀门开度；
- 三个储罐的液位高度；
- 储罐、阀门和连接管道；
- 每个储罐的 SP 游标和与当前液位的偏差；
- 液位的 % 与 mm 双读数；
- 管段流量标签和随流量变化的流动效果；
- 阀门下的“自动 / 手动 / 串级 / 未用”控制方式；
- 单回路与串级控制接线，可用“控制线”按钮显示或隐藏；
- 当前仿真时间。

操作：
- “−”缩小；
- “+”放大；
- “适配”完整显示全图，首次打开自动适配；
- “⛶”放大到全屏区域；
- 再次点击或按 Esc 退出全屏；
- 放大后，普通视图和全屏视图均可按住图形拖动；拖动到边界时停止。
- 液位、换热器的普通与全屏视图分别记住缩放和位置，互不覆盖。
- 切到曲线等页面再返回，保留原来的视图；刷新页面后重新适配。
- 窗口尺寸变化时，适配视图随区域调整；已手动调整的视图尽量保持原来的关注位置。

实时检测值
--------------------------------
LI101 / LI102 / LI103
  三个罐液位，单位 %。

FI101 / FI102 / FI103
  给水流量、级间流量，单位 L/min。

出口流量
  FV104 后排出的流量，单位 L/min。

PI101
  泵出口压力，单位 kPa。

九、曲线页面
--------------------------------
曲线页分为三个标签：

1. 液位曲线
   - LI101、LI102、LI103；
   - 各回路对应 SP 线；
   - 纵轴为 % 液位。

2. 流量曲线
   - FI101、FI102、FI103；
   - 出口流量；
   - 纵轴为 L/min；
   - Y 上限可填写 1～20 L/min；
   - 留空表示自动缩放。

3. 开度曲线
   - P101；
   - FV101～FV104；
   - 纵轴为 0～100% 开度。

曲线交互
--------------------------------
位号显隐
  点击图例中的位号按钮，隐藏或显示对应曲线。

标注线
  点“隐藏标注”后，标注线和当前时间标一起消失；
  点“显示标注”后，标注线、时间标和当前时间一起出现。

标注线拖动
  标注线不会跟随鼠标随意移动。
  按住标注线并拖动，才改变标注位置。

当前时间标
  时间标显示标注线对应的时间。
  可以单独拖动时间标，放到不遮挡曲线的地方。

坐标轴
  - 拖动 X 轴区域，缩放横轴；
  - 拖动 Y 轴区域，缩放纵轴；
  - 拖动绘图区，平移整个视图；
  - 液位和开度纵轴有固定范围，流量纵轴可设置上限。

最新视图
  回到自动跟随最新数据的状态。

清空曲线
  清空当前浏览器会话的曲线历史。
  回到冷态不会清空曲线，只有“清空曲线”或重新登录的新会话才会从空曲线开始。

十、保存、云端方案和工程文件
--------------------------------
学生端有三套不同的保存机制，不要混用。

1. 保存当前状态
   - 冷态可以直接保存，或先暂停仿真再保存；
   - 运行中且未暂停时不能保存；
   - 保存到服务器上的“当前状态”；
   - 用于随后通过“恢复上传保存状态”恢复。

2. 云端方案 1 / 2 / 3
   - 先选择方案；
   - 暂停仿真；
   - 点“上传云端”；
   - 教师必须已开放“学生上传”，否则不能上传；
   - 点“从云端下载”会把该方案恢复到当前仿真；
   - 恢复后统一是未启动状态。

3. 导入工程
   - 学生端不提供工程导出；
   - 点“导入工程”，选择 `.ylproj` 文件；
   - 导入会覆盖当前状态并恢复为未启动；
   - 工程文件最大 8 MB。

自动恢复快照
--------------------------------
在退出登录、重新登录或强制关闭页面时，系统会尽量自动保存一份恢复快照。
学生下一次登录仍先进入全新冷态；
如果界面检测到没有“当前状态”但有自动恢复快照，点“恢复上传保存状态”可尝试恢复该快照。
如果已经有手动保存的当前状态，则以“恢复上传保存状态”对应的手动保存内容为准。

状态行
--------------------------------
控制区会显示：
- 当前状态是否已保存；
- 当前选中的云端方案是否已上传；
- 云端上传是否开放；
- 最近自动保存时间。

十一、评分
--------------------------------
评分对象
  关闭评分
  单罐评分
  系统评分

单罐评分可选：
  LI101 1#罐
  LI102 2#罐
  LI103 3#罐

评分流程
1. 回到冷态；
2. 选择评分方案；
3. 单罐评分再选择评分罐；
4. 点“开始评分”；
5. 系统清空当前回路配置并开始评分计时；
6. 重新搭建回路、整定参数并启动仿真；
7. 评分结束后查看操作、控制、安全、收益和总分。

评分时间
- 从“开始评分”后开始计算；
- 包含搭回路时间、未启动时间、暂停时间和运行时间；
- 默认限时 30 分钟；
- 评分未开始或未结束时不能进入评分页，点击会提示原因；
- 评分结束后显示结束时间，成绩封存。

评分分项
- 操作：冷态起步、回路搭建、投自动和按时稳态；
- 控制：稳态误差、整定时间、超调；系统评分还考察同步和流量平衡；
- 安全：低限、高限、溢流和空罐；
- 收益：送液量和给水利用率。

十二、退出
--------------------------------
点右上角“退出”会：
1. 尽量保存当前学生状态到恢复快照；
2. 结束该学生的浏览器会话；
3. 返回登录页。

如果只是关闭浏览器标签页，系统也会尝试通过页面离开事件自动保存。
要长期保留重要结果，请使用“保存当前状态”或“上传云端”。

十三、参数、曲线与云端上传
--------------------------------
学生端不提供参数、曲线和工程导出，课堂数据统一通过云端方案保存。

点击“上传云端”时，系统会同时保存：
- 当前仿真状态；
- 回路与 PID 参数快照；
- 当前曲线视图状态；
- 液位、流量、开度三张曲线图片。

教师可在教师端选择学生，导出其已上传到云端方案 1 的参数和曲线图片。
曲线图片会保留上传时的曲线显隐、坐标范围、缩放平移和标注线状态。
如果学生尚未上传，或旧版上传缺少参数/图片，教师导出包会标记“请学生重新上传”。

十四、常见问题
--------------------------------
问：为什么学生端找不到导出参数、曲线或工程按钮？
答：当前学生端只负责把状态、参数和曲线保存到云端；导出由教师在教师端统一完成。

问：为什么液位为 0 时阀门不动？
答：先检查回路方向。液位回路通常使用反作用；方向不对时，PID 输出可能一直向关闭方向变化。

问：为什么 FV101 只开一点，流量就和 FV102/FV103 全开差不多？
答：FV101 由泵提供压头，FV102/FV103 由上一级罐的重力压头驱动。它们的最大流量和工况不同，不能用同一个开度直接比较。

问：改了同一个液位的 SP，另一个阀门回路没有变化？
答：SP 是液位设定值。共享同一液位的回路只在发生修改时同步一次，不会在每次界面刷新时覆盖用户输入。

问：为什么上传云端按钮不可用？
答：需要同时满足：仿真已暂停、教师已开放学生上传、已选择云端方案。

问：重新登录后为什么是空界面？
答：这是安全设计。重新登录先进入冷态，需要从“恢复上传保存状态”或云端方案恢复。

问：曲线为什么没有清空？
答：回到冷态不会清空曲线。要清空历史请使用“清空曲线”按钮。

问：评分为什么不能在运行中开始？
答：评分方案和评分对象只能在冷态选择，评分会话从冷态开始才能保证判定一致。

十五、换热器模型（教师开放后）
--------------------------------
教师开放换热器后，学生登录时可在“实验模型”中选择“换热器”。换热器与三级液位使用
独立的状态、曲线、云端方案和评分记录，互不覆盖。

主要位号
  TI1104  出口蒸汽温度，单位 ℃，是推荐单回路的被控量；
  FI1105  蒸汽流量，单位 kg/s；
  FV1102  冷却水阀；
  FV1101  燃料阀；
  FV1105  蒸汽阀。

控制操作
  - FV1102、FV1101、FV1105 未被回路占用时可手操；
  - 单回路可选 TI1104 或 FI1105 作被控量，并选择未被占用的阀门；
  - 串级可自由选择阀门、主环和副环，搭建规则与三级液位一致；
  - 运行中不能切换单回路/串级，也不能套用模板；
  - 回到冷态会复位换热器、回路和评分状态。

推荐方案
  换热器推荐工况由教师端“推荐工况”一键应用，采用单回路：

      TI1104 出口温度 → FV1102 冷却水阀

  推荐模板使用 COOL_480 工况，出口温度给定值为 450 ℃。该单回路能让冷却水阀保持
  在有效调节行程内；串级仍保留给学生自由搭建，但不作为推荐模板。

曲线和评分
  - 温度曲线单位 ℃，流量曲线单位 kg/s，开度曲线单位 %；
  - 三页曲线均支持曲线显隐、X/Y 轴拖动缩放、标注线和时间标拖动；
  - 换热器评分与液位评分同为四类权重：操作 20、控制 50、安全 20、效益 10；
  - 评分未开始或未结束时不能进入评分结果页。

历史字段口径（接口与导出）
  换热器曲线历史按列式对象保存，字段依次为：
  t、ti1104、sp、ti1103、fi1105、spf、fv1102、fv1105、fv1101、
  fuel、mw、level、twall、twater、qhx。
  其中 t 为仿真时间；ti1104、ti1103、twater、twall 为温度；fi1105、spf、
  fuel、mw 为流量；fv1102、fv1105、fv1101 为开度；level 为汽包液位；
  qhx 为换热量。字段名与模型接口一致，不随界面显示名变化。
