三级液位 PID 云仿真  教师端功能手册
========================================

版本：当前 YunLevel 云版
更新日期：2026-09-24

一、登录
--------------------------------
1. 打开部署好的系统网址，例如：

   http://服务器公网IP:8080

2. 选择“教师登录”。
3. 在“实验模型”中选择“三级液位”或“换热器”。
4. 输入总教师口令。
5. 点“进入教师端”。

重要说明：
- 系统只有一个总教师账号，负责管理全部班级；
- 教师口令由服务器的 `YUN_TEACHER_CODE` 决定；
- 正式上课前必须修改测试口令；
- 教师可使用控制 / 仿真、曲线和评分页面进行课堂演示；
- 教师演示使用独立会话，不进入学生在线列表，也不写入学生评分记录；
- 多个教师 PC 可以打开看板，但教师演示本身共用一个教师仿真会话，不建议多人同时修改教师仿真。

二、教师页面
--------------------------------
教师登录后可见：

- 控制 / 仿真；
- 曲线；
- 评分；
- 教师看板；
- 班级管理。

普通学生没有：
- 推荐工况；
- 高分模板；
- 教师看板；
- 班级管理。

三、教师演示控制
--------------------------------
教师在“控制 / 仿真”页可以使用与学生端相同的功能：

- 启动、暂停、回到冷态；
- 单回路 / 串级切换；
- 自由搭建回路；
- 修改 SP、Kp、Ti、Td、手动输出；
- 投手动 / 投自动；
- 改正作用 / 反作用；
- 查看 PID 计算过程；
- 手操泵和未被回路占用的阀门；
- 前馈偏置；
- 保存当前状态；
- 云端方案 1 / 2 / 3；
- 上传云端；
- 从云端下载；
- 导出工程；
- 导入工程；
- 查看液位、流量和开度曲线；
- 单罐评分和系统评分。
- 仿真图查看 SP 游标、液位 %/mm、管段流量、阀门控制方式和控制接线。
- 搭建冲突、Ti=0 等非法操作会返回明确错误提示。
- 评分未结束前不能进入评分页，点击会提示当前状态。

教师不受学生“上传云端已关闭”的限制，教师可以自行上传和恢复自己的云端方案。

教师独有模板
--------------------------------
推荐工况
  一键搭建系统推荐的回路和参数，用于课堂演示和控制方案对比。

高分模板
  一键应用高分参考模板。
  当前含单回路和串级参考方案，具体内容以实际内核版本为准。
  应用模板前应保持未启动或按要求先暂停，避免覆盖正在分析的状态。

仿真图操作（教学演示）
  首次打开自动完整显示。使用 + / − 缩放，放大后在普通或全屏视图中按住拖动。
  “适配”按钮恢复全图；再次点击全屏按钮或按 Esc 退出全屏。
  液位、换热器分别保存普通和全屏视图的位置与缩放，切换页面不会清空。
  这些视图只保存在本次页面内，刷新页面后重新适配，不写入仿真快照。

四、教师看板
--------------------------------
打开顶部“教师看板”。

1. 在线学生

   表格显示：
   - 学号；
   - 姓名；
   - 班级；
   - 运行 / 暂停 / 未启动状态；
   - LI101、LI102、LI103 液位；
   - 回路数量；
   - 当前评分状态；
   - 操作按钮。

   可按班级筛选。
   刷新按钮可手动重新拉取数据。
   看板通过服务器推送持续更新，课堂中可实时观察在线情况。

2. 查看学生曲线

   在某个学生的操作列点“查看曲线”。
   下方“学生详情”会切换为该学生的：
   - 液位曲线；
   - 流量曲线；
   - 开度曲线。
   三页均可切换。

   学生曲线视图支持：
   - 点击图例隐藏或显示对应曲线；
   - 拖动 X 轴缩放；
   - 拖动 Y 轴缩放；
   - 拖动绘图区平移；
   - 显示 / 隐藏标注；
   - 拖动标注线；
   - 拖动当前时间标；
   - 回到最新视图。

   这里的曲线功能与学生的曲线页保持一致，便于教师复盘。

五、学生云端状态
--------------------------------
教师看板中的“学生云端状态”用于查看并读取学生上传的方案。

模型筛选
--------------------------------
顶部可选“全部模型 / 三级液位 / 换热器”。选择“全部模型”时，在线学生、云端方案和评分记录
会同时显示；每行都有“模型”列，读取或导出时按该行模型处理。

筛选
--------------------------------
先选择“班级”，再选择“学生”。
只有选中的班级和学生数据会显示在列表中。

列表字段
--------------------------------
- 上传时间；
- 云端方案编号；
- 模型；
- 学号；
- 姓名；
- 班级；
- 仿真时间；
- LI101 / LI102 / LI103；
- 来源；
- 操作。

读取到教师仿真
--------------------------------
点“读取到教师仿真”后：
1. 系统先自动保存教师当前仿真状态；
2. 学生云端方案被载入教师仿真；
3. 页面切换到控制 / 仿真；
4. 载入后的状态统一为未启动。

恢复载入前状态
--------------------------------
读取学生方案后，教师看板会显示：
   “恢复载入前状态”

点击它可以恢复教师读取学生方案之前自动备份的状态。
这个备份独立于教师的云端方案 1 / 2 / 3。

导出学生云端方案 1
--------------------------------
在“学生云端状态”区域先选择班级，再在云端学生清单中勾选一名或多名学生。
可点“全选本班”一次选中全班，也可用“取消选择”清空勾选。
点“导出云端 ZIP”后，系统会只读取这些学生已经上传的云端方案 1。
导出包中包含：
- 班级参数汇总 CSV；
- 导出清单 CSV；
- 导出说明；
- 每名学生各自的参数 CSV；
- 每名学生各自的液位、流量、开度曲线 PNG。

导出文件会带模型名：
- 单模型：文件名和 ZIP 内容标明“三级液位”或“换热器”；
- 全部模型：文件名标明“全部模型”，ZIP 内按模型分文件夹；
- 参数 CSV、评分 CSV 和工程文件也带对应模型名，便于混班归档。

教师导出不读取学生当前在线状态，也不会从实时曲线临时生成图片。
如果学生尚未上传，或旧版上传缺少参数/图片，导出包会标记“请学生重新上传”。

学生上传权限
--------------------------------
顶部按钮：
   “学生上传：关闭 / 开放”

每个学生每学期可以保存云端方案 1、2、3，但上传权限由教师控制。
关闭后，学生点击上传会提示教师尚未开放云端上传功能。
教师自己的上传不受这个开关限制。

注意：
- 学生必须暂停仿真后才能上传；
- 学生上传的是独立快照，不会影响教师；
- 读取学生数据前系统会先备份教师状态，仍建议教师自己养成先保存的习惯。

六、评分记录
--------------------------------
教师看板底部是“评分记录”。

显示字段：
- 时间；
- 模型；
- 学号；
- 姓名；
- 班级；
- 模式；
- 总分；
- 控制；
- 安全；
- 收益。

按班级筛选
--------------------------------
可以先在顶部选择班级，再打开评分记录。

导出评分 CSV
--------------------------------
点“导出评分 CSV”，下载当前筛选范围内的评分记录，便于汇总分析。

清空记录
--------------------------------
- 选择某个班级时，只清空该班记录；
- 选择“全部班级”时，清空全部评分记录；
- 清空前请确认已经导出备份。

七、班级管理
--------------------------------
打开顶部“班级管理”。

1. 新建班级

   填写：
   - 班级名称；
   - 班级码。
   点“新建班级”。

   班级码要求：
   - 长度 2～32；
   - 只能使用字母、数字、下划线或短横线；
   - 不能和已有班级重复。

2. 班级列表

   可查看：
   - 班级名称；
   - 班级码；
   - 学生数；
   - 状态；
   - 操作。
   选择班级后可编辑名称、班级码和启用状态。

3. 添加学生

   填写学号和姓名，点“添加学生”。

   学生登录时会校验：
   - 班级码是否存在且启用；
   - 学号是否在名单中；
   - 学生账号是否启用；
   - 姓名是否和名单完全一致。

4. 修改学生

   在名单表格中修改学号、姓名和启用状态，再把该行保存。
   停用或删除学生后，该学生当前会话会停止。

5. Excel / CSV / 手动导入

   支持：
   - `.xlsx`；
   - `.xls`；
   - `.csv`；
   - 手动粘贴文本。

   Excel / CSV 会读取第一张工作表并自动识别“学号”和“姓名”列。
   手动粘贴格式：

       学号,姓名
       20260001,张三
       20260002,李四

   合并导入
     保留原名单，将新名单合并进去。

   覆盖导入
     先完整校验全部行，再替换当前班级名单。
     如果存在重复学号或格式错误，原名单不会被破坏。

6. 导出名单 CSV

   导出当前班级的学生名单，编码为 UTF-8。

7. 删除班级

   删除班级后，该班学生不能继续登录。
   删除前应确认已经导出名单和需要的评分记录。

八、教师状态保存和工程文件
--------------------------------
教师的控制页也提供：

- 保存当前状态；
- 恢复上传保存状态；
- 云端方案 1 / 2 / 3；
- 上传云端；
- 从云端下载；
- 导出工程；
- 导入工程。

规则与学生端一致：
- 保存当前状态必须暂停仿真；
- 恢复后为未启动状态；
- 教师上传不受学生上传开关限制；
- 导入工程会覆盖教师当前状态；
- 读取学生方案前会自动备份教师当前状态。

九、曲线功能
--------------------------------
教师自己的曲线页与学生端相同：

- 液位曲线纵轴为 %；
- 流量曲线纵轴按模型显示：三级液位为 L/min（默认上限 20），换热器为 kg/s（默认上限 95）；
- 开度曲线纵轴为 0～100%；
- 点击位号可隐藏或显示；
- 标注线可显示、隐藏和拖动；
- 时间标可拖动；
- X/Y 轴可拖动缩放；
- 绘图区可拖动平移；
- 可回到最新视图；
- 可清空曲线。

教师查看学生曲线时使用同一套交互规则。

十、课堂操作建议
--------------------------------
1. 上课前

   - 登录教师端；
   - 确认教师口令已经修改；
   - 检查班级和名单；
   - 给学生发对应班级码；
   - 在教师看板确认学生在线。

2. 发布任务前

   - 先用自己的教师演示会话跑通单回路或串级；
   - 确认推荐工况和高分模板能正常运行；
   - 清空上一次的学生上传方案或提前说明云端方案编号用法。

3. 学生操作过程中

   - 在教师看板按班级筛选；
   - 选择学生查看实时曲线；
   - 需要课堂展示时读取学生云端方案；
   - 读取前系统会自动备份教师当前状态。

4. 评分结束后

   - 查看评分记录；
   - 按班级导出 CSV；
   - 需要长期保留时另外备份服务器 `data/` 目录。

十一、云端参数与曲线导出
--------------------------------
教师导出的内容只来自学生主动上传到云端方案 1 的数据。
每名学生的参数 CSV 包含学生信息、液位、SP、回路 PID、执行器实际/指令开度和上传状态；
若搭建了串级，会分别输出主环和副环参数行。

三张曲线 PNG 是学生点击“上传云端”时随状态一起上传的图片。
图片保留上传时的图例显隐、坐标范围、平移缩放和标注线状态。

教师看板旧的“在线学生参数导出”和“实时曲线图片导出”当前不显示入口，以避免误用在线数据；相关实现代码保留，后续需要时可以再启用。

十二、服务器与数据
--------------------------------
服务器运行数据位置：

    /opt/YunLevel/data

主要文件：
- `classes.json`：班级和名单；
- `state/`：学生状态；
- `history/`：曲线历史；
- `score_records.jsonl`：评分记录；
- `settings.json`：全局设置；
- `submissions/`：学生云端方案；
- `teacher_backups/`：教师状态备份。

升级或维护前建议备份整个 `data/` 目录。
不要把运行数据提交到公开源码仓库。

十三、常见问题
--------------------------------
问：为什么教师能进入仿真，但学生列表没有教师？
答：教师演示使用独立会话，不进入学生在线列表，也不写入学生评分记录。

问：读取学生方案后怎么回到教师原来的状态？
答：点击教师看板的“恢复载入前状态”。系统在读取学生方案前已经自动备份。

问：学生上传按钮一直是灰色？
答：先确认教师已开放学生上传，并且学生已经暂停仿真。

问：多个教师同时打开看板会有问题吗？
答：查看看板通常没问题。但所有教师共用一个教师仿真会话，若多人同时操作教师控制页，会互相覆盖，建议只指定一名操作教师。

问：评分记录怎么汇总？
答：在教师看板按班级筛选后点“导出评分 CSV”。

问：学生重新登录后没有上次界面怎么办？
答：这是按当前实现设计的安全行为。学生可点击“恢复上传保存状态”，或从云端方案 1 / 2 / 3 下载已保存内容。

十四、换热器模型
--------------------------------
教师在登录页选择“换热器”即可进入换热器教师端。教师端始终可以选择该模型，不受学生
开放开关限制。

学生开放开关
  在教师端的云端数据/课堂设置区域使用“换热器模型：关闭/开放”按钮：
  - 关闭：学生登录页隐藏换热器选项，直接请求换热器登录会被服务器拒绝；
  - 开放：学生登录页显示换热器选项，可按班级码、学号、姓名进入。

推荐工况
  换热器“推荐工况”固定为单回路：

      TI1104 出口温度 → FV1102 冷却水阀

  使用 COOL_480 工况，出口温度给定值 450 ℃，自动、正作用。该方案避开蒸汽阀近开关
  特性造成的饱和区，适合课堂演示和单回路整定。串级模板仍可在冷态自由搭建。

教师功能覆盖
  - 教师看板可按模型分别查看学生，液位和换热器不会混在同一张表；
  - 学生详情、参数汇总、曲线、评分记录和云端方案均按模型隔离；
  - 换热器参数包含 TI1104、SP、TI1103、FI1105、SPF、FV1102、FV1101、FV1105；
  - 教师读取换热器学生方案前同样会自动备份教师当前换热器状态。

部署检查
  更新后的镜像必须同时包含：

      /app/bin/YunEngine
      /app/bin/HxEngine

  缺少任意一个，对应模型会提示内核启动失败。换热器数据位于 `data/hx-state/`、
  `data/hx-history/`、`data/hx-submissions/` 和 `data/hx-teacher_backups/`，与液位数据分离。
