# 控制工作台与参数滑块验证说明

本文记录本次控制页 UI 改动的使用方式、自动验证入口和浏览器验收项。已有的内核、会话、评分和部署流程继续参考[交接须知](交接须知的注意文件.md)；本页用于补充本次 UI 验证。

## 界面与操作

- 左侧“回路”页以紧凑列表展示已搭建的单回路和串级；点击一项后，在参数栏编辑该回路。1440px 起使用左侧 224px / 自适应仿真图 / 右侧 360px 三栏；900–1439px 参数栏位于图下方；900px 以下按回路、仿真图、参数顺序纵向排列，DOM 与键盘顺序保持一致。
- PID 计算过程默认折叠，展开后只显示所选回路，可通过“显示 PID”和“隐藏计算”切换。
- 仿真图下常驻关键读数：液位显示 LI101/LI102/LI103；换热器显示出口温度、目标、入口温度、蒸汽流量。单位沿用模型描述符，缺值显示“—”。其余检测值保留在“全部测量值”中。全屏时收起检测值以留出画布空间。
- 左侧“手操”页保留当前模型的手操输入与“应用手操”操作。已被回路占用的执行器继续按原规则禁用。
- “搭建回路”与顶部“工程 / 方案”使用折叠区域，展开后可使用原有添加、保存、恢复、上传、下载和导入操作。
- 未应用的参数草稿保留在原表单中。仅切换选中回路，或接收回路结构不变的 SSE 状态更新，不会丢失草稿；实时 PV 和运行状态仍会刷新。增删回路、切换模型、恢复工程或退出登录不属于这项草稿保留保证。
- 侧栏数字输入不再弹出滑块，鼠标点击或 Tab 聚焦均直接编辑。设备操作卡仍使用其内嵌滑块，与共享数字草稿同步。
- `Ti` 支持关闭积分：关闭状态使用 `inf`，`Ti=0` 仍为非法值。
- 数字输入及设备卡内嵌滑块均只修改草稿；回路参数仍需点击“应用参数”，手操仍需点击“应用手操”才生效。
- 参数栏用文字和样式区分未应用草稿、正在应用、已应用、失败及只读。应用时阻止重复提交；失败保留草稿，可检查后重试；请求等待期间的新输入也不会被迟到回复清掉。
- 学生只读 SP 和教师观察窗口的禁用输入继续保持权限限制；设备卡只读滑块不可操作。

## 自动验证入口

Windows 使用 PowerShell 7：`C:\Program Files\PowerShell\7\pwsh.exe`，脚本使用 UTF-8。进入仓库根目录后执行：

```powershell
npm run check
if ($LASTEXITCODE -ne 0) { throw 'JavaScript syntax check failed' }
npm run test:controls
if ($LASTEXITCODE -ne 0) { throw 'Control workspace tests failed' }
```

Linux 同样从仓库根目录执行 `npm run check` 和 `npm run test:controls`。

`npm run test:controls` 统一调用 `scripts/test-controls.js`。Runner 使用当前 Node 可执行文件，依次执行：

1. 工作台、滑块、反馈、动效和工艺图设备脚本的 `node --check`，具体列表见 `scripts/test-controls.js`。
2. 回路选择、滑块范围、关键读数、反馈、动效、设备映射和命令草稿测试，具体列表见同一 runner。

任一步失败即返回非零退出码。该入口只使用 Node 内置模块，不需要安装依赖、启动仿真服务或连接测试/生产服务器。测试数量以当前输出为准。

GitHub Actions 的 `.github/workflows/control-workspace.yml` 在 PR、相关前端文件推送及手动触发时运行，环境为 Ubuntu、Node 24；依次执行 `npm run check` 和 `npm run test:controls`。推送门禁也覆盖 fork 的功能分支，便于独立验证提交。这两项覆盖语法、选择状态、滑块、读数和异步草稿逻辑；不包含 C++、浏览器布局或完整 E2E。完整回归与 Linux CI 结论分别记录，不能互相替代。

## 浏览器验收清单

在隔离的本地测试实例中，分别检查 `tank` 和 `hx` 的学生、教师控制页面。使用 1536×724、1240px、1439/1440px、899/900px、390px 和 200% 缩放；核对控制台错误。

- [ ] 左侧回路列表切换正确；参数栏只显示选中回路表单，显示 PID 时计算内容与选择一致。
- [ ] 在回路 A 输入尚未应用的参数，切到 B 后再回 A，草稿不变；运行中等待 SSE 更新后重复这一检查。
- [ ] 未修改输入可随服务器状态同步，PV、手动/自动状态和列表读数持续刷新。
- [ ] 删除前面的回路后，原选择随同一回路移动；删除当前选择后，工作台显示一个仍存在的回路；清空后显示空状态。
- [ ] 两模型的回路选择互不干扰；退出后重新登录不继承上一会话的选择或回路草稿。
- [ ] “回路 / 手操”切换、搭建回路折叠、工程方案折叠可以用鼠标和键盘操作；原按钮仍完成对应操作。
- [ ] 点击或 Tab 聚焦侧栏数字输入，不生成滑块弹层；Tab 继续到下一字段，数字可直接编辑。
- [ ] 数字输入与设备卡内嵌滑块只改草稿；点击相应的应用按钮后服务器状态才改变。
- [ ] `Ti` 有限值、关闭积分与直接输入 `inf` 状态一致，`Ti=0` 仍被拒绝。
- [ ] 回路占用的手操、学生只读 SP、教师观察窗口禁用输入继续限制编辑；设备卡内嵌滑块遵循相同权限。
- [ ] 隐藏/显示 PID、展开全部测量值、缩放及全屏仿真图不遮挡工作台控件；窄屏滑块和应用按钮可操作。
- [ ] 请求失败保留草稿，应用中不重复下发命令，迟到回复不清除新输入。
- [ ] 两模型关键读数单位正确，手动串级 PV 使用实时测量值而非 PID 上次计算缓存；冷态液位图为空，随 SSE 读数更新。
- [ ] 登录角色状态、错误播报、键盘焦点、只读说明和减少动画设置可用；长回路标题及长数值不撑开栏宽。
