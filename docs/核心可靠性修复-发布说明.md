## 规则变化

学生始终采用教师规则，SP、评分模式、考核罐、时长、带宽和扰动只读。允许启动、暂停、泵阀手操、搭回路、PID整定及手动/自动切换；外部工程导入、教师模板、内部推进及退出内核命令禁止。

教师配置采用完整合并和校验，每次保存评分配置/开关递增版本。未评分会话立即应用；正在评分的会话固定本轮版本，下一轮采用新配置。结果逐会话返回`applied`、`pending`或`failed`，失败不会显示为全部成功。液位和换热器默认单对象480秒、系统1500秒；各模式使用自己的目标、带宽和时长。换热器先初温后目标。

首个在线教师控制演示，后续登录只观察并附着已有内核。观察窗口禁止写操作，退出仅释放自己的连接；控制窗口退出后最早仍在线的观察窗口接任，演示不重置。

关闭、刷新、离开页面、主动退出、评分中重置或连续90秒无心跳，封存本轮为零分，记录实际已用评分时间和结束原因。浏览器每15秒发送心跳；切后台本身不发结束请求。网络完全中断时离开请求可能送不到，由服务器心跳超时封存。内核故障、网关重启也封存为异常结束，禁止续接。

学生重新登录进入冷态，恢复自己的当前状态、云端方案或恢复快照，只保留实验配置、清除评分运行态并应用当前教师规则。新评分获得新编号；评分进行中禁止恢复方案。重复结束只生成一条记录；旧会话或旧轮次请求不能结束新评分。

## 接口与兼容

已有API路径保留。权限拒绝403，评分冲突409；无效请求400，正文超限413，内核忙/失败503。

| 接口/数据 | 新增约定 |
| --- | --- |
| 登录、`GET /api/me` | `sessionId`；me同时返回当前`attemptId`和`viewOnly` |
| `POST /api/session/heartbeat` | JSON包含`sessionId`和`attemptId`（未评分时null） |
| `POST /api/session/end` | 同样携带两个编号，幂等封存并释放会话 |
| 教师设置响应 | `settings.scoreConfigRevision`、逐会话`applications`及总体`ok` |
| `state.score` | `attemptId`、`configRevision`、`effectiveConfig`、`endReason` |
| 成绩JSON/CSV | 评分编号、配置版本及结束原因；JSON保留本轮实际配置 |
| 内部命令 | `SCORE_FINISH`仅网关调用，保留时间、封存零分；`SCORE_END`仅清运行态，不用于异常封存 |

稳定错误码包括`INVALID_URL`、`INVALID_COOKIE`、`INVALID_JSON`、`BODY_TOO_LARGE`、`INVALID_SCORE_CONFIG`、`COMMAND_FORBIDDEN`、`IMPORT_FORBIDDEN`、`VIEW_ONLY`、`ASSESSMENT_LOCKED`、`SCORING_DISABLED`、`SCORE_START_NOT_COLD`、`SCORE_RESET_REQUIRED`、`STALE_SESSION`、`STALE_ATTEMPT`、`SESSION_ENDED`、`ENGINE_BUSY`、`ENGINE_TIMEOUT`和`ENGINE_EXITED`。

结束原因：`completed`正常完成；`page_closed`离开页面；`logout`主动退出；`reset`主动重置；`heartbeat_timeout`长断线；`kernel_failure`内核故障；`server_restart`重启；`server_shutdown`正常关停；`account_change`/`class_change`账号或班级变更。

旧设置缺失字段补当前默认值。旧成绩原样读取，不重新计分。模型魔数、二进制结构、液位会话键和目录、历史字段顺序及PID `Ki=1/Ti`保持原有约定。新元数据写入JSON，进行中的评分另存`data/active-attempts.json`；重启处理后清理对应条目，不引入数据库迁移。

最终复核补充：未评分会话即使已启动，也立即更新评分模式和规则；状态立即同步实际配置版本。恢复准备阶段不广播旧评分、不推进旧运行态，与开始评分/退出操作串行处理，避免并发恢复绕过封存。

每个内核只允许一条在途命令、最多64条排队命令；HTTP操作也限制64项等待。超时清理全部等待项并终止内核，迟到输出不能用于后续命令。停止与实际退出分开跟踪，正常退出失败时依据真实进程状态强制结束。
