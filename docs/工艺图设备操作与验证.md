# 工艺图设备操作与验证

更新日期：2026-10-04。点击设备后，在桌面设备旁查看操作卡；900px 以下使用底部面板。两模型使用相同交互，沿用原生 HTML/CSS/JS。设备拓扑、绘图尺寸、API、评分规则及二进制快照未改变。

## 设备与操作

| 模型 | 点击入口 | 操作 |
| --- | --- | --- |
| 液位 | P101 | 泵开度草稿与单独应用 |
| 液位 | FV101、FV102、FV103、FV104 | 未被回路占用时调开度；占用时进入所属回路 |
| 液位 | T1、T2、T3 | 查看罐液位，进入关联回路；未连接时预选搭建表单 |
| 换热器 | TI1103 | 查看、调节入口温度 |
| 换热器 | E1102、TI1104、FI1105 | 查看出口温度或蒸汽流量，进入关联单回路或串级 |
| 换热器 | FV1102、FV1105 | 未被回路占用时调开度；占用时进入所属回路 |
| 换热器 | FI1102 | 查看冷却水流量和冷却水阀关联回路 |

只为现有可见设备设置入口，不额外显示隐藏设备。读数直接使用当前 SSE 状态，单位为 %、℃、kg/s，缺值显示“—”。同一设备关联多个回路时，优先选择已选回路；否则先让用户选择，避免操作其他回路。

操作卡和侧栏共享原始表单草稿。关闭、重开、切换设备或 SSE 刷新不会偷偷应用或清空草稿。PID 默认折叠；串级明确区分主环、副环，副环可单独设置手动输出。数字输入和滑块均只修改草稿。

- “应用参数”明确提交当前回路参数。
- “投手动 / 投自动”使用已应用的 PID，不顺带提交草稿。
- “应用手动输出”只提交输出草稿，并保持已应用 PID；自动状态下必须先投手动。
- “应用手操”只提交当前设备，不批量改动其他泵阀。
- 请求中阻止重复提交，保留焦点；失败提示原因并保留草稿。回复期间又修改的字段继续保持未应用。
- 迟到回复不能清理另一个设备的反馈，也不能向已删除或替换的同名回路继续发命令。

学生 SP 采用教师规则并保持只读；观察窗口只可查看，全部写入字段和动作不可用。服务器权限与观察身份依赖核心修复 PR #1；本 PR 不扩大权限，不增加教师模板或内部命令入口。

## 鼠标、触屏与键盘

工艺图命中区域在屏幕上至少 44px，重叠时按离设备中心最近的位置判断。设备形状和已有状态标签均可打开同一操作卡。只显示一个操作卡，桌面位置受视口约束；手机面板内部可滚动，考虑底部安全区。

相机 PR #2 将移动距离超过 6 CSS px 的手势识别为拖动；点击或轻触才激活设备。拖动开始立即收起操作卡，取消手势、视口外松开均不激活。普通和全屏相机状态继续分别保存。

设备入口可 Tab 到达，Enter / Space 打开。Esc 关闭操作卡并恢复设备焦点；全屏下先关闭操作卡，第二次 Esc 才退出全屏。底部面板不锁住键盘焦点；离开最后一个控件后继续页面顺序。只读数字可查看，滑块和写入动作不可操作。系统减少动画偏好保留文字反馈，关闭移动、缩放和加载旋转。
