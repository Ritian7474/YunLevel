# 管道水力模型与 PID 整定验证

日期：2026-10-04。基于 `fix/core-reliability` 的独立分支 `feat/pipe-hydraulics`。

## 范围

实现三级液位的 FV102、FV103 和 FV104 重力管路。三只容器继续共用原有直径 150 mm、高度 1000 mm；独立容器尺寸的建议暂不实现。

一次实验中的管路几何数值固定。没有加入工况事件，也没有调整 PID 算法、执行器速度、仪表响应、噪声或评分权重。给水侧保持原有泵流量边界 `Qin = Qpump × FV101 开度`，本版不重建泵和给水管网。换热器的物理方程不在此次改动范围内。

## 连接方式及水头假设

现有仿真图注释为“上一级出口 → 下一罐顶部入口”，因此沿用自由出流、顺序串联的模型，不引入下游液位背压或倒流。

有效水头沿用原有口径 `ΔH = 上游液位 h`。这隐含自由出口与上游罐底同标高；三级顶部进料可由逐级降低容器安装高程实现。示意图不作为安装高程测量依据。如果之后明确为底部淹没连通或给出不同出口高程，需要另行改水头关系，不能只调整管长来代替高程。

采用不可压缩水、充满管路的准稳态流动假设。管长产生沿程阻力，没有把它换算成任意的纯延迟；也不引入管道充液、空气或水锤过程。

## 数学模型

每段管路满足 Darcy–Weisbach 沿程损失与局部损失关系：

\[
h=\left(f(Re,\varepsilon/d)\frac{L}{d}+K_m+\frac{K_v}{u^2}\right)
\frac{(Q/A_p)^2}{2g},\qquad A_p=\frac{\pi d^2}{4}
\]

- `L`：管长 m；`d`：内径 m；`ε`：绝对粗糙度 m。
- `u`：阀门开度比例 0～1。保留原有开度与有效节流面积的口径，`Kv = 1/Cd²`，`Cd = 0.61`。
- `Km`：阀门之外的固定局部阻力系数，不随时间改变。
- `Re = (Q/Ap)d/ν`，水的运动黏度固定为 `ν = 1.004×10⁻⁶ m²/s`，对应约 20℃。
- 层流 `Re ≤ 2000` 使用 `f = 64/Re`；湍流 `Re ≥ 4000` 使用 Swamee–Jain 近似；中间区域连续插值，是教学模型的过渡区近似。
- 对流量二分求解 40 次。阀门关闭或无有效水头时流量为零。

沿程阻力关系依据 [EPA EPANET 水力模型说明](https://github.com/USEPA/EPANET2.2/blob/master/User_Manual/docs/3_network_model.rst)。过渡区插值和等效阀阻力属于本项目明确采用的近似，不是具体设备标定结果。

容器继续采用原有物料守恒方程：

\[
A_t\dot h_1=Q_{in}-Q_{12},\quad
A_t\dot h_2=Q_{12}-Q_{23},\quad
A_t\dot h_3=Q_{23}-Q_{out}.
\]

空罐边界按当前储水与本子步进水量限制可排水量，避免数值积分排出不存在的水。溢流记入对应容器的物料流出账，累计溢流体积按 `m³ × 1000` 转换为 L；这同时修复原有溢流记账误差。

教师使用的前馈反算和评分参考流量同步使用新方程。总流量不再直接与阀门开度成正比，反算阀位时同时扣除沿程和固定局部损失。

配置位于 `native/config.h` 的 `GRAVITY_PIPES`。这是经过下述整定实验验证的教学起始值，不是实物设备测量值；修改后需重新编译并重复验证。

|---|---:|---:|---:|---:|---:|

## 固定对象下的整定验证

统一条件：三罐初始为空；泵指令 60%；FV102/103/104 全开；LI103 控制 FV101；T3 目标液位 50%；前馈关闭；运行 1500 s。没有中途改变目标或注入扰动。

`Ti` 使用本项目既有口径 `Ki = 1/Ti`，不改成 `Kp/Ti`。误差、超调采用满量程百分点；尾段误差为最后 300 s 的平均绝对误差。

“稳定时间”定义为最后一次离开 `[48%,52%]` 后的下一秒，并要求后续至少持续保持 120 s。这是本测试的持续入带指标，不是重新定义产品评分规则。

扫描网格：`Kp ∈ {0.1,0.3,0.5,0.7,1,3,10}`、`Ti ∈ {100,300,500,700,1000,1500,3000}`、`Td ∈ {0,60,120,240}`，共 196 组。9 组同时满足持续入带和全过程无溢流。这个数量只描述当前有限网格，不代表全部合理参数的占比，也不是唯一正确参数的证明。

结果说明该固定对象能区分明显迟缓、合理整定和激进整定，并存在多组可用参数。以上结果限于这条三级单回路及当前初始条件；各罐独立回路、串级及不同目标的教学难度还需教师试用和进一步标定。

## 验证与复现

学生前馈在液位与换热器内核中均固定关闭：网关启动学生进程时附加 `--no-pid-bias`，HTTP 命令权限同时禁止学生 `SET_BIAS`。旧存档中的开启状态、液位高分模板和直接内核开启命令均不能绕过进程限制。教师自己的演示进程保留前馈开关。现有按钮已经是教师专用，本次不修改界面布局。

前馈限制有独立测试覆盖两模型的旧存档加载、重置、模板、实际 PID 项快照及 HTTP 权限。

Windows 侧使用 PowerShell 7，在项目根目录运行：

```powershell
npm test
& ./native/build/selftest_tank.exe --sweep |
    Set-Content -Encoding utf8 .tmp-pid-sweep.csv
```

Linux 侧扫描入口为 `./bin/selftest_tank --sweep`。CSV 仅为本地测试输出，不需要放入运行数据或提交学生记录。

本地完整回归已通过：19 个 Node 测试、液位 28 项内核检查、换热器 63 项内核检查、159 项端到端检查。水力检查包括层流解析解、无管损孔口解析解、单调性、正反算一致性、空罐/溢流守恒和固定 PID 对照。

远程测试机 `192.168.88.102` 关闭 SSH 连接；其 Tailscale 地址 `100.116.186.113` 在 SSH banner 阶段超时。已核对客户端公钥与本机保存的服务器指纹均符合 AGENTS.md。Linux/测试服务器回归尚未完成；未更新运行服务或发布生产版本。
